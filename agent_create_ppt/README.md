# LLM Agent 生成投影片方法
(1) 依靠 GPT 的 Image2 進行圖片 "直接生成"，如：
``` Prompt
以上的內容，幫我生成一張 16x9 的圖片，將數學式子由上而下寫出來，並在式子右邊用繁體中文解釋他的意思
```
但是仍然建議文字要自己 Tune 過，但整體大綱排版可以靠 AI 生成的，也可以利用 AI 進行報告模板的 POC

(2) nano banana pro 2
要逐個告知想要生成的模板風格以及寫法，他可以穩定照著我們所定義的格式做。
如果不做細節告知，他預設的模板表現毀極度糟糕
``` prompt
這一段文字，幫我改成用工整簡潔的黑板板書風格，生成一張 16 x 9 的圖片來統整筆記
```
